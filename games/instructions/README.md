# Blind Rover

A clean, minimalist classroom communication game designed for Grade 2 and up.

---

## 🎮 How to Play

- **The Pilot (Blind Player):**
  - Enter the Pilot Name on the start screen before launching the mission.
  - Sits facing away from the screen.
  - Controls the robot rover using <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> or <kbd>Arrow Keys</kbd>.
- **The Class (Mission Control):**
  - Faces the projector screen.
  - Guides the pilot using clear spoken instructions ("Move right", "Step down", "Hold UP!").
- **Leaderboard & Scores:**
  - Upon mission success, the completion screen displays a dual-view: Point Aggregator on the left and Leaderboard on the right highlighting the pilot's new score!
- **Quick Restart:**
  - Press <kbd>R</kbd> at any time to instantly start a fresh round.

---

## 🗺️ Map Elements

- **🟢 Green Dot:** Safe path tile (walk here!).
- **☠️ Red Skull:** Hazard bomb tile (stepping here causes an instant BOOM!).
- **🔒 Padlock:** System lock tile (Pilot must hold the announced arrow key for 3.0 seconds).
- **🎨 Color Speller:** Letter lock tile (Spelling challenge to defuse).
- **🏁 Flag:** Exit zone! Reach here to win.

---

## ⚙️ Settings

Click the **⚙️** icon in the top right to configure:
- **Game Mode:** Choose between **Countdown**, **Count Up**, or **Score Mode**.
- **Time Limit:** Adjust the round duration (30s, 45s, 60s, 90s, 120s).
- **Rover Lives:** Customize heart lives (1 to 9).
- **Lock Challenges:** Set Color Speller and Arrow Hold challenge counts.
- **Leaderboard Records:** Reset or clear saved high scores.
- **Sound & Music:** Adjust volume or toggle background audio.
